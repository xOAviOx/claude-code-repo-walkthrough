Entrypoints

How Claude Code boots up — from zero to full REPL

⚡

cli.tsx Bootstrap

The very first thing that runs. Handles fast paths that skip the full CLI:

  • --version / -v — prints version, zero imports
  • --daemon-worker — spawns lean daemon
  • remote-control — bridge mode for remote env
  • daemon — long-running supervisor
  • ps / logs / attach / kill — session mgmt
  • new / list / reply — template jobs
Falls through → main.tsx
🔧

init.ts Setup

Called once at startup. Bootstraps the environment:

  • Configuration validation & loading
  • Graceful shutdown handlers
  • Analytics & feature flags (GrowthBook)
  • OAuth, JetBrains, git detection
  • mTLS, proxy, API preconnect
  • Telemetry (deferred until trust)
🖥️

main.tsx 800KB+

The heaviest module. Sets up Commander.js CLI parsing, wires up the REPL, and renders the Ink-based TUI. This is why fast paths exist — to avoid loading it for simple operations.

03

Query Engine & Loop

The heart of the system — an infinite loop of LLM calls and tool execution

🎛️

QueryEngine.ts Orchestrator

One QueryEngine per conversation. Owns:

  • Message history (mutableMessages)
  • File state cache
  • Abort controller
  • Usage tracking
  • Permission denial tracking

Key method: submitMessage() — an async generator that processes input, builds prompts, calls the query loop, and yields SDK events.

🔄

query.ts Core Loop

The infinite loop that powers everything:

query loop
while (true) {
  1. Apply tool result budget
  2. Run snip compaction
  3. Run microcompact
  4. Run context collapse
  5. Run auto-compact
  6. Check blocking token limits
  7. Stream from Anthropic API
  8. Execute tool calls (parallel)
  9. Handle stop hooks
  10. Continue if tool_use, else return
}

Coordinator Mode

Multi-agent orchestration — coordinator spawns and manages workers

Doesn't execute tools directly

👷 Worker 1
Research
👷 Worker 2
Implementation
👷 Worker 3
Verification
1Research — parallel workers investigate
2Synthesis — coordinator reads findings, crafts specs
3Implementation — workers make targeted changes
4Verification — workers test changes
⚠️

Key design: Workers can't see the coordinator's conversation. Every prompt must be self-contained.
